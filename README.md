# MiniBank

A simple banking application built as part of the SAP Labs Bulgaria Mentorship Program 2026.

## Tech Stack
- Backend: Java, Spring Boot
- Database: PostgreSQL (planned)
- Frontend: React (planned)

## MVP Features (planned)
- User registration and login (authentication & authorization)
- View account details and update personal info
- Money transfers between accounts
- Admin: freeze / unfreeze accounts

## Run locally
1. Clone the repository
2. Run `MinibankApplication`
3. Open http://localhost:8080/api/hello
